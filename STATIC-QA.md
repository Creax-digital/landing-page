# Статическая подготовка — 11 сентября 2026

## Результат

Готов самостоятельный каталог `dist/github-pages/`: 16 HTML-страниц на русском, английском и упрощённом китайском плюс 404. Он не требует Node.js, Cloudflare Worker, аккаунта Sites или серверного преобразования изображений на хостинге.

Существующий проект Sites и его серверный вариант сохранены. GitHub, живой сайт `creax.digital`, настройки Pages и DNS не изменялись. Workflow подготовлен, но ещё не запускался в пользовательском GitHub.

## Выполнено

- Основное содержание, контакты и ссылки доступны в исходном HTML без запуска JavaScript.
- Для каждой языковой страницы записан правильный `html lang`; canonical и взаимные hreflang сохраняют текущий раздел. Для входной страницы выбора языка устранён дубль английского заголовка.
- Все адреса страниц завершаются `/` и соответствуют файлам `index.html` в каталогах; нет маскировки неизвестных адресов под главную страницу.
- `robots.txt`, `sitemap.xml` и manifest сохранены в виде файлов. Sitemap содержит 16 адресов и языковые альтернативы, без выдуманных дат обновления.
- Organization, WebSite, WebPage/CollectionPage и Service связаны постоянными идентификаторами. Сервисная разметка проверяется на соответствие видимому тексту. Не добавлены вымышленные оценки, адреса, цены или результаты.
- Подготовлены адаптивные WebP-изображения с проверенными реальными размерами; сохранён JPEG fallback. Маленькие иконки и облегчённая копия существующей картинки для социальных превью создаются автоматически, без изменения оригиналов.
- Неиспользуемые исходные видео и изображения не попадают в публичный артефакт. В исходниках они сохранены.
- `llms.txt` актуализирован как необязательный указатель на языковые страницы и услуги. Он не объявляется инструментом гарантированной индексации или ранжирования.
- GitHub Actions проверяет pull request; публикация разрешена только отдельному заданию после успешной сборки `main`. Версии действий закреплены SHA, зависимости — lockfile; разрешены только конкретные версии установочных сценариев нативных инструментов.

## Проверено

- Линтер и TypeScript — без ошибок.
- 9 тестов статического результата: полный HTML и уникальные метаданные, языковые связи, sitemap/robots/CNAME, JSON-LD, локальные ссылки и якоря, изображения, социальные иконки и зависимости CSS/JS, статический HTTP и размеры артефакта.
- Все 16 страниц возвращают HTTP 200 при прямом открытии через простой файловый сервер, в том числе при User-Agent Googlebot и другом предпочитаемом языке. Неизвестные страницы возвращают HTTP 404 и содержат `noindex`.
- Изолированная копия без `.openai/hosting.json`, старого `node_modules` и прежнего хранилища пакетов: установка из реестра с `--frozen-lockfile`, затем весь `check:static` завершились успешно.
- 8 существовавших серверных тестов прошли после основных изменений; обычная серверная сборка также работает. Итоговый статический артефакт собран отдельно после серверной проверки.
- `git diff --check` не выявил ошибок пробелов и конфликтных маркеров.

## Что не утверждается

Это техническая подготовка, не подтверждение индексации. Google, Яндекс, Bing и AI-системы сами решают, обходить ли сайт, индексировать ли его и цитировать ли его в ответах. Сайт должен стать публично доступен на домене, после чего потребуется проверка в инструментах вебмастеров.

Чистая сборка проверена на macOS с Node.js 24 и pnpm 11.19.0, не на реальном runner GitHub Linux. В этой итерации не выполнялся новый полный браузерный аудит, Lighthouse или замер полевых Core Web Vitals. Предыдущий визуальный аудит описан отдельно в `QA.md`; после публикации стоит повторить быстрый просмотр на реальном телефоне и компьютере. Соответствие фактических кейсов реальным проектам должен подтвердить владелец.
